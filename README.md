# zeanDO

一本摊开在浏览器里的纸质手帐：课表、待办、随手记，都记在同一张纸上。

在线试用：<https://haidi0.github.io/zeando-web/>

## 它能做什么

- **今日**：一眼看到下一节课倒计时、今天要交的事、最近的随手记
- **课表**：周视图节次格，支持单双周与调课角标，课程色块竖排课名
- **待办**：逾期 / 今天 / 明天 / 本周 / 稍后五段分组，也可切日历视图
- **随手记**：`#标签` 即时高亮，30 秒记一条，标签可筛选
- **⊕ 落笔**：底部中央全局快速记录入口

## 隐私说明

无账号、无服务器、无统计。所有记录只存在你自己浏览器的 `localStorage` 里（键名前缀 `zd1:`），换设备或清浏览器数据会丢，可在「我的 → 导出 JSON」随时带走一份。

## 本地运行

零依赖，纯原生 HTML / CSS / JavaScript，无构建步骤。

```bash
# 方式一：直接双击 index.html
# 方式二：起个本地服务
python -m http.server 8000
```

## 设计与实现约定

- 视觉方向：纸感手帐（暖白纸面 / 墨色文字 / 一点砖橘），禁渐变、禁 emoji 功能图标
- 设计令牌集中在 `css/tokens.css`，业务样式不写表外魔法值
- 对比度按 WCAG 2.1 逐色实测，深浅双主题可用；320px 窄屏不破版
- 触控热区 ≥44px，支持 `prefers-reduced-motion` 降级
